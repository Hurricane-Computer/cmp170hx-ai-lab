# Curated technical data

These files are explicit technical projections of the research records, not copies of raw logs or private checkpoints.

- [capacity-evidence.json](capacity-evidence.json): external77.5/72-GiB lead, archived full-word test audit, historical47-GiB alias and CPU method counterexamples; no new GPU capacity result.
- [peer-memory.json](peer-memory.json): historical Stage42/F and later G directed matrices, exact module fingerprints, separate 8/64-GiB CMP64 observations and the scoped native-discovery refusal.
- [bar2-root-observations.json](bar2-root-observations.json): normalized D/E RPC statuses and actual eight-byte root comparisons; no private addresses or logs.
- [driver-candidates.json](driver-candidates.json): seven built/live-tested driver variants, A–E BAR2 failures, working F/G with checked copies, exact source hashes and corrected compressed/ELF module evidence.
- [cards.json](cards.json): non-identifying variant observations and evidence timestamps.
- [clock-trials.json](clock-trials.json): the five observed CMP40 clock steps, short-copy hashes, test limits and attributed prior art.
- [bandwidth-load.json](bandwidth-load.json): one bounded1350-MHz load, CUDA-event throughput, explicit read+write byte counts, output hashes and sampled telemetry; no long-term or full-memory qualification.
- [memory-sizing.json](memory-sizing.json): original sizing-getter correspondence, distinct FB/FLA domains, calculated examples and the new original memory-object anchor; no new physical-memory measurement.
- [startup-memory.json](startup-memory.json): original creator-to-runtime-guard connection and buffer-to-size-input dataflow; call contract, content producer and physical backing remain open.
- [usable-size.json](usable-size.json): exact-release configured-size decoder, original formatter boundary and one synthetic region-accounting case; no physical-capacity result.
- [geometry-inputs.json](geometry-inputs.json): historical ID-response provenance, ordinary RRL histogram, preformatter range bookkeeping and bounded BIT-I negatives; no extra-capacity result.
- [tpc-sources.json](tpc-sources.json): first four-vector observation on both variants, with original selector addresses.
- [cp-witness.json](cp-witness.json): requested nonzero witness values versus actual readback and effective topology.
- [firmware-catalog.json](firmware-catalog.json): twelve original-image hashes, geometry profiles and exact partition tables; no firmware binaries.
- [experiment-ledger.json](experiment-ledger.json): method/result/scope records and links to interpretations.
- [gsp-object-map.json](gsp-object-map.json): the original GPU/GA100 method-selection chain and its explicit limits.

`observed` fields describe their recorded timestamp. `owner-established` values were accepted from the existing setup rather than requalified. A null full-capacity-tested field is intentional: this campaign did not perform intensive full-VRAM qualification.

[mailbox-candidate.json](mailbox-candidate.json) contains the scoped G mechanism, native discovery refusal, six directed capabilities, checked ordinary-copy hashes, static-BAR1 prerequisite and vendor firmware fingerprints. It contains no raw logs or firmware payloads.

[discovery-and-firmware.json](discovery-and-firmware.json) records normal passthrough discovery boundaries, exact BIOS/module/tool hashes and the two observed stored PCI settings. Source analysis, offline comparisons and live observations are separate.

[training-commands.json](training-commands.json) contains the original normal App08 command forms, six selector-pair table, mask-dependent port selection and explicitly calculated historical examples; no new hardware observation.

[fb-regions.json](fb-regions.json) contains the ordinary exported-region observations, filtered-view limits and exact first-party ABI fingerprints. These are configured ranges, not hidden-memory tests.

[capacity-followup.json](capacity-followup.json) separates the 12 small live verifier controls, matching-version static fault mapping and historical configuration comparison. No additional capacity is asserted.

[configured-memory-geometry.json](configured-memory-geometry.json) records the first ordinary FBP/FBPA/LTC geometry GETs and separately calculated consistency checks. Reported units do not establish hidden physical memory.
