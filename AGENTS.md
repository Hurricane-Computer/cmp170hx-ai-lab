# Research publication contract

This is the curated public CMP170HX research lab, not the private experiment workspace.

- Separate observed values, original-source analysis, owner-established baselines, theoretical estimates, third-party reports and hypotheses.
- Distinguish accepted register readback, changed effective topology, reported memory and demonstrated usable memory. Never infer the last from the first.
- Preserve negative results with their exact scope. Reopen an approach only when a new mechanism distinguishes it.
- Preserve timestamps. An old hardware snapshot is not current state.
- The owner-established74SM baseline is not an invitation to requalify it or ECC on every maintenance pass.
- Curate fields explicitly. Do not bulk-copy a research output tree, checkpoint, raw log, access helper or firmware image into this repository.
- Do not publish credentials/tokens/keys, private network endpoints, host or VM identifiers, user paths, serial numbers, GPU UUIDs or private transcripts. Vendor and physical-memory manufacturer names are technical facts and may be documented.
- Original proprietary firmware inputs stay external; reference their versions and hashes. Attribute original external code and experiments.
- This public file grants no hardware or account permissions. Follow the owner's direct session authorization and applicable local instructions for any actual experiment.
- Run the publication validator and inspect the exact diff before a push. Push only to this repository; do not overwrite unrelated branches or force-push as routine upkeep.
- Keep notes readable and useful. Avoid empty commits, speculative success language, repeated baseline tests and documenting unchanged scans as breakthroughs.
